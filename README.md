🎮 Hangman Game in Python
A simple, text-based Hangman game built with Python. Guess the hidden word one letter at a time, and try to solve it before you use all six incorrect guesses! ❤️
✨ Features
- 🎲 Randomly selects a word from a list of five predefined words.
- 🔤 Lets the player guess one letter at a time.
- ❤️ Allows up to 6 incorrect guesses.
- ✅ Shows correctly guessed letters and hides the rest.
- ⚠️ Checks invalid input and prevents repeated guesses from costing a life.
- 🏆 Displays a win or game-over message.
- 🎨 Includes emoji messages and decorative, bordered headings.
🧰 Requirements
- Python 3
- A terminal, command prompt, or Python editor such as IDLE or VS Code
No external libraries are required. The game uses Python's built-in random module.
🚀 How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:
   python hangman.py
   On some systems, you may need to use python3 hangman.py instead.
4. Enter a single letter when prompted. Type carefully, and guess the word before you run out of lives!
🎯 Words Included
The game randomly chooses from these five words:
